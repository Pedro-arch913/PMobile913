📱 PMobile913

Aplicativo mobile de chat desenvolvido com Flutter e Dart como parte de um projeto acadêmico do curso Técnico em Informática do Instituto Federal de Alagoas (IFAL) — Campus Arapiraca.

O projeto tem como objetivo desenvolver uma aplicação mobile, aplicando conhecimentos de programação, desenvolvimento de interfaces e integração com tecnologias para dispositivos móveis.

🚧 Status do projeto: Em desenvolvimento.
📋 Sobre o projeto

O PMobile913 é um projeto acadêmico voltado ao desenvolvimento de um aplicativo de comunicação por chat. O repositório reúne o código-fonte e os recursos necessários para a evolução da aplicação.

🛠️ Tecnologias utilizadas
Flutter — Framework para desenvolvimento de aplicações multiplataforma.
Dart — Linguagem de programação utilizada no projeto.
SQLite — Tecnologia de banco de dados local, por meio do pacote sqflite.
HTTP e Dio — Bibliotecas disponíveis no projeto para comunicação com serviços e APIs.
Shared Preferences — Armazenamento local de preferências simples.
Google Fonts e Font Awesome — Recursos para estilização e ícones da interface.
